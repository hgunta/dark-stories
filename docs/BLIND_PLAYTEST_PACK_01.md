# Dark Stories — Blind Playtest Pack 01 (NO SOLUTIONS)

**For first-time testers only.** This sheet contains no solutions. Please
do not consult the editorial repo, discuss the answers with previous testers,
or search for the stories before playing.

**Test one case at a time.** Read only the public premise. Before any
Yes/No questions, write your first guess and the first three things you would
ask. Then play with a moderator who has read the private case brief
(`ORIGINAL_STORY_SLATE_01.md`) and commits to honest Yes/No/Irrelevant
answers. A fully correct theory immediately ends a round; no keyword checks.

## Moderator guidance (do not hand to testers beforehand)

Use the private canonical solutions from `ORIGINAL_STORY_SLATE_01.md`.
Give Yes to true partials. Accept an equally coherent alternative when
the public premise does not exclude it. If a reader offers a complete
explanation, end promptly rather than demanding exact detail. Record
ambiguous questions and any incorrect denial for revision.

**Initial gate**: try two independent first-time testers per case. If they
find the explanation arbitrary, stop development; do not manufacture
difficulty. If both find it coherent and interesting, proceed to five
independent blind sessions and then test the actual Luna moderator.
